# First Public Release Notes Draft

This release is intended to publish Universal Brain as a **source-visible software and architecture checkpoint** with explicit evidence boundaries.

## Included

- deterministic executive/control-plane architecture;
- model/transport-neutral intelligence fabric;
- durable mission/checkpoint infrastructure;
- authority-gated Tool Gateway contracts;
- engineering-agency planning, verification and recovery infrastructure;
- semantic code/LSP integration surfaces;
- worker/service durability mechanisms;
- Windows/WSL2/Ollama/endurance validation tooling;
- repository-local security, alignment and verification documentation.

## Evidence boundary

The release does not claim that every environment-dependent capability has been production-proven.

In particular, Windows/WSL2 isolation, Ollama pressure behavior, long-duration endurance and large-system autonomous engineering claims remain gated by target-machine evidence unless the release commit contains the required artifacts and verification record.
