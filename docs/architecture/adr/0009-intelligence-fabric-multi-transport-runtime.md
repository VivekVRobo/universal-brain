# ADR-0009: Intelligence Fabric / Multi-Transport Model Runtime

**Status:** Implemented as an extensible runtime slice; live provider routes remain operator-gated.

Universal Brain separates three identities: **model identity**, **access route**, and **runtime transport**. The deterministic Kernel continues to own canonical goals, permissions, commitments, evidence, and audit state. Provider conversations are non-canonical continuity references only.

A model may expose API, browser, desktop-app, or local routes. Route failure, quota exhaustion, or authentication loss must not incorrectly mark the underlying model unavailable. The router uses capability, empirical local performance, privacy, health, cost, transport preference, context capacity, and quota admission. It contains no vendor-name preference branches.

Model Council outputs and multi-model agreement are not verification evidence under ALN-011. Consequential actions remain behind the existing ToolGateway and capability system.

Browser/desktop transports must use operator-authorized sessions and must not bypass CAPTCHA, MFA, rate limits, or provider restrictions. The V3 runtime includes generic browser/desktop transport boundaries, session supervision, provider-neutral streaming, tool-call normalization, Context Compiler V2, durable route telemetry, deterministic escalation graphs, and Council disagreement/synthesis metadata. Provider-specific live UI selectors still require machine-specific smoke testing before they are treated as production-ready.
